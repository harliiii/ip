# LinkShield — учебный проект о фишинге

## Запуск
1. Установите Python 3.10 или новее.
2. Откройте терминал в папке проекта.
3. Создайте виртуальное окружение (необязательно, но рекомендуется):
   - Windows: `python -m venv .venv` и `.venv\Scripts\activate`
   - macOS/Linux: `python3 -m venv .venv` и `source .venv/bin/activate`
4. Установите зависимость: `pip install -r requirements.txt`
5. Запустите: `python app.py`
6. Откройте адрес `http://127.0.0.1:5000` в браузере.

## Что умеет программа
- принимает URL или домен;
- анализирует HTTPS, символ @, IP вместо домена, Punycode, количество поддоменов, длину URL, порт, подозрительные слова и дефисы;
- выводит условный балл риска и объяснение каждого правила.

## Важные ограничения
Это учебный прототип на эвристических правилах. Он не посещает сайт, не проверяет содержимое страницы, DNS, сертификат или репутацию домена и не является ML-моделью. Низкий балл не означает, что сайт безопасен. Не вводите настоящие пароли или платёжные данные во время демонстрации.
